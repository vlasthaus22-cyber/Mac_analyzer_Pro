# MAC Analyzer Pro v1.0.69

## Исправление IP из DDIO

- Пустой IP устройства теперь заполняется прямым сопоставлением MAC с
  MAC резервации или MAC аренды DDIO.
- Логика не читает и не сравнивает IP коммутатора. Заполнение работает
  при пустом, другом или некорректном IP коммутатора.
- Проверяются основной MAC, второй MAC SmartRoom и ранее подтверждённые
  альтернативные MAC.
- Подстановка выполняется после восстановления идентификаторов из
  истории, чтобы в DDIO мог найтись восстановленный MAC.
- Уже заполненный корректный IP не перезаписывается. Possible IPs остаются
  дочерними диагностическими значениями и не создают новые устройства.
- В результате сохраняются источник `DDIO`, тип совпадения и MAC, по которому
  найден IP.

## Безопасность сопоставления

- Совпадение Device ID больше не может назначить IP записи с другим
  реальным MAC. Device ID используется как совместимый fallback только если
  MAC у итогового устройства отсутствует.
- Серверный и автономный браузерный pipeline используют одинаковую
  последовательность обогащения.

## Проверка

- Проверены четыре выбираемые колонки DDIO: MAC/IP резервации и MAC/IP аренды.
- Добавлены регрессионные сценарии для прямого MAC → IP, второго MAC SmartRoom,
  независимости от IP коммутатора и конфликта Device ID.
- Полный набор: 103 тестовых модуля, 367 Python-сценариев плюс JavaScript-
  проверки. Все прошли.
- Stress-test: 200 000 строк, 3 повторных запуска, рост удерживаемой памяти
  0,00 MiB.
