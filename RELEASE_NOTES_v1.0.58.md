# MAC Analyzer Pro v1.0.58

Полный выпуск с исправлением переполнения памяти IndexedDB, хронологии
помещений и графиков последовательных финальных обогащений.

## Исправления

- Устранена ошибка `Failed to execute 'put' on 'IDBObjectStore': Data cannot be
  cloned, out of memory`. Производный DDIO-индекс больше не дублируется в общей
  записи состояния, совпадения IndexedDB читаются ограниченно, а большие
  коллекции и несериализуемые значения безопасно нормализуются перед записью.
- Ошибка DataClone/Out-of-memory теперь имеет понятный этап и код диагностики.
  Незавершённый Final удаляется, последний успешный Final остаётся активным.
- Хронология помещения содержит все финальные состояния, включая периоды, когда
  комнаты или устройства не было. Повторное появление не создаёт ложное
  изменение из пустого значения, если значение уже было достоверно известно.
- Каскадные фильтры ТБ, города, площадки, этажа и помещения не показывают
  значения другой ветви. Поиск учитывает иерархию и устройства, а единственный
  результат выбирается автоматически и сразу показывает хронологию.
- Кнопка «Проверить изменения всех устройств» показывает результат сравнения
  каждого устройства выбранной комнаты между двумя последними Final.
- В графике добавлений/отсутствий первый Final используется только как база.
  Добавленные устройства находятся выше нулевой линии, «Отсутствовало» — ниже.
- График общего числа устройств показывает каждое финальное обогащение от
  первого до последнего, а не только последнюю пару.
- DDIO по-прежнему заполняет IP только при точном совпадении MAC и только когда
  поле IP устройства пусто; существующий IP не перезаписывается.

## Проверки

Добавлены регрессии для крупного/cyclic payload IndexedDB, ограниченных
конфликтов, временного отсутствия помещения, появления комнаты не в первом
Final, каскадных фильтров, базового первого Final и знака серий графика.
Выполняются полный набор тестов, ESLint, Prettier, проверка автономного HTML и
сборка полного Windows-комплекта с исходниками и сохранёнными данными v1.0.27.

Для полной программы скачивайте **MAC-Analyzer-v1.0.58-Full.zip**.
