# MAC Analyzer Pro v1.0.73

Исправительный релиз для больших переносимых баз и DDIO-обогащения.

## Исправления

- Удалён жёсткий отказ для `.madb` больше 1 ГБ.
- Файл и база из выбранной папки читаются одинаково потоково.
- Final-снимки и Inventory записываются в IndexedDB пакетами, а UI держит только ограниченный предпросмотр.
- История из большой базы не накапливается безгранично в JavaScript-памяти.
- Обычная DDIO-загрузка теперь использует тот же профиль колонок, что и массовая: `Column3`/`Column2` для резервации и `Column10`/`Column9` для аренды.
- Пустой IP устройства заполняется из DDIO по точному совпадению основного, дополнительного или ранее подтверждённого MAC. IP коммутатора в этой логике не участвует.

## Проверка

- Потоковое чтение файла с заявленным размером 2 ГБ.
- Пакетное чтение истории с ограниченным UI-предпросмотром.
- DDIO-сопоставление reservation, lease, secondary MAC и независимость от IP коммутатора.
