# MAC Analyzer Pro v1.0.63

Полный выпуск с исходным кодом, автономным HTML, Windows-комплектом и чистой
инициализированной SQLite-базой. Пользовательские файлы, история и локальные
секреты в публичный архив не включаются.

## Исправлено

- Исправлено определение даты выгрузки: сначала используется дата из имени
  файла, затем `created/modified` из метаданных XLSX, и только после этого —
  системная дата файла. В интерфейсе сохраняется источник выбранной даты.
- DDIO распознаёт обычную пару столбцов MAC/IP наряду с Lease и Reservation.
  При точном совпадении MAC найденный IP заполняет пустой IP устройства, но не
  заменяет уже известное значение.
- Кнопка списка переговорных, где изменилось всё оборудование, теперь показывает
  адрес и открывает полную карточку/хронологию выбранной комнаты.
- Иерархический адрес из строки `ТБ, Город, Площадка, Этаж, Помещение`
  корректно разбирается и отображается в автономном и серверном режимах.

## Новые данные и аналитика

- Добавлен столбец «Время аутентификации устройства», включая автоматическое
  сопоставление колонки, Excel-даты, поиск, экспорт и постоянное хранение.
- Добавлен показатель числа устройств без помещения и две сводки для таких
  устройств: по производителям и по моделям.
- Графики переименованы в «Добавленные и отсутствующие устройства» и
  «Динамика изменения MAC-адресов».

## Проверка

- Модульные и интеграционные тесты frontend/backend, lint и синтаксис.
- API/UI smoke, автономная HTML-сборка и проверка полного Windows-архива.
- Регрессии даты XLSX/имени файла, DDIO MAC/IP, времени аутентификации,
  раскрытия комнаты и аналитики устройств без помещения.
