# MAC Analyzer Pro v1.0.68

## Массовое обогащение

- Добавлен режим **Автоматизация → Массовое обогащение** для трёх папок:
  основные файлы, SmartRoom и DDIO.
- Поддерживаются CSV, TSV, TXT, JSON, XLS, XLSX и XLSM.
- Доступны сопоставление по одинаковой календарной дате и подбор ближайшей
  выгрузки в заданном диапазоне (по умолчанию 24 часа).
- Каждый основной файл формирует отдельный цикл
  `△ Main + △ SmartRoom + △ DDIO → □ Final`.
- Перед запуском можно вручную переназначить SmartRoom/DDIO, отключить цикл и
  проверить неназначенные файлы.
- Циклы выполняются последовательно через существующий атомарный pipeline;
  DDIO остаётся вспомогательным источником и не создаёт лишние устройства.
- В серверном режиме папки сканируются по путям Windows без одновременной
  загрузки всех файлов в память. Для CSV используется дата из имени или точная
  дата создания файла Windows; для XLSX также читаются свойства документа.

## Исправления

- Исправлено чтение UTF-8 CSV с русскими названиями помещений: строгий UTF-8
  больше не проигрывает ошибочно выбранной Windows-1251.
- Исправлено автоматическое распознавание колонок `Smartroom ID`, `Room` и
  `Device ID`: сильные идентификаторы больше не захватываются общими полями
  `room` и `model`.
- Массовое обогащение использует те же правила восстановления моделей,
  заполнения пустого IP из DDIO, сохранения Final и истории, что и одиночный
  запуск.

## Проверка

- Выполнен реальный интерфейсный сценарий из двух последовательных CSV-циклов:
  оба Final созданы, IP заполнен из DDIO, Smartroom ID и Device ID сохранены.
- Добавлены регрессионные тесты планирования дат, ручного переназначения,
  серверного сканирования/импорта папок, UTF-8 CSV и идентификаторов колонок.
- Полный исходный код, автономный HTML, Windows-комплект и данные входят в
  полный архив релиза.
