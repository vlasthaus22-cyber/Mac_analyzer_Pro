# MAC Analyzer Pro v1.0.82

## Полный состав переговорной в аналитике

- Карточка **«Отклонения IP коммутатора»** сохраняет индикатор **NEW** и
  показывает все устройства выбранной переговорной, а не только отклонения.
- Для каждого устройства доступны MAC, IP устройства, IP коммутатора, порт,
  производитель, модель, тип, hostname, Device ID, серийный номер, время
  аутентификации и источник.
- Строка с отличающимся IP коммутатора выделяется отдельно.

## Переговорные без Smartroom ID

- Smartroom ID остаётся главным ключом помещения.
- Если ID отсутствует только у части устройств, они присоединяются к комнате по
  нормализованному пути ТБ → город → площадка → этаж → помещение, но только
  когда этому пути соответствует ровно один Smartroom ID.
- При нескольких Smartroom ID для одного пути программа не угадывает комнату и
  не формирует ложное отклонение.
- Адрес площадки без названия помещения больше не считается идентификатором
  комнаты.

## Восстановление IP устройства из DDIO

- Пустое или невалидное значение IP в Final заполняется из DDIO по точному MAC.
- Сопоставление не зависит от IP коммутатора и не смешивается с аналитикой его
  смены.
- Распознаются стандартные, Cisco-dot и вложенные значения вида
  `Calling-Station-ID=00:11:22:33:44:55@radius`.
- Единственный валидный Possible IP допускается как однозначное значение;
  несколько альтернатив остаются диагностикой и не подставляются случайно.
- Источник сохраняется как `DDIO` в `fieldSources.ip`, а значение записывается в
  активный Final до его атомарного сохранения.

## Совместимость и проверка

- Логика синхронизирована между автономным HTML, IndexedDB и Python/SQLite.
- Кеш аналитики Final обновлён до версии 4; старые Final не удаляются и
  автоматически пересчитываются.
- Добавлены регрессионные тесты полного состава комнаты, отсутствующего и
  неоднозначного Smartroom ID, вложенного MAC и DDIO Possible IP.

Release содержит один файл `MAC-Analyzer-v1.0.82-Full.zip` с автономным HTML,
Windows runtime, backend, полным исходным кодом, тестами, OUI, чистой рабочей
SQLite и очищенной исторической базой. Секреты и исходные пользовательские
выгрузки не включаются.
