# MAC Analyzer Pro v1.0.66

Полный выпуск содержит актуальный исходный код, автономный HTML, Windows-
комплект, локальную SQLite-базу, OUI-справочники и совместимые данные полного
комплекта v1.0.27. Секреты, токены, пароли, webhook-адреса и инженерные сессии
исключаются из публикуемой копии.

## Исправлено

- Dashboard теперь сразу рассчитывает четыре требуемых показателя по выбранной
  паре финальных обогащений: **Изменённые**, **Отсутствуют**, **Помещений с
  изменениями** и **Изменилось всё оборудование**.
- Устранена задержка, при которой основные KPI ожидали сканирования всей истории
  выгрузок и нескольких повторных API-запросов. Основное сравнение Final
  выполняется первым, расширенная аналитика загружается в фоне.
- Backend больше не десериализует текущий снимок повторно и не читает таблицы
  истории/перемещений, когда для точного сравнения уже доступны два Final.
- В автономной версии агрегат полного Final сохраняется в IndexedDB и повторно
  используется при открытии Аналитики. При изменении Final кеш автоматически
  сбрасывается, поэтому устаревшие показатели не отображаются.
- Большие списки производителей, помещений и деталей изменений ограничены на
  уровне ответа API без потери точных счётчиков. Журнал изменений отображает по
  100 устройств и поддерживает последовательную дозагрузку.
- Добавлены SQLite-индексы для MAC-хронологии, перемещений и времени изменения.

## Проверка

- Реальная UI-проверка на изолированной SQLite-базе: два Final по 5 000
  устройств, 200 изменённых, 100 отсутствующих и 100 помещений с изменениями.
- Проверены переход в Аналитику, журнал изменений, категории, фильтры,
  дозагрузка и отсутствие ошибок/предупреждений в консоли браузера.
- Полный штатный набор: **100/100 файлов, 357 тестовых функций**.
- Bounded-memory стресс: 200 000 строк, три повторных обогащения, удержанный
  прирост памяти 0,00 MiB.
- Проверены lint, синтаксис, frontend/backend, API/UI smoke, IndexedDB,
  SQLite, автономный HTML и полный релизный ZIP.
