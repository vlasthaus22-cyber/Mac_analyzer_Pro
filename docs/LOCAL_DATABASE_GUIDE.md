# Локальная база MAC Analyzer Pro

MAC Analyzer Pro поддерживает два локальных хранилища. Выберите один основной способ и регулярно создавайте резервную копию.

## Рекомендуемый вариант: папка программы и MADB

1. Откройте `MAC-Analyzer-Pro.html` в Chrome или Edge.
2. Нажмите **Локальная база** в верхней панели.
3. Нажмите **Выбрать локальную папку** и выберите постоянную папку, например `MAC Analyzer Data`.
4. Разрешите браузеру чтение и запись. Программа создаст каталоги `database`, `imports`, `exports`, `settings`, `logs` и `backups`.
5. Если в `database` уже имеется `mac-analyzer-data.madb`, выберите **Подключить существующую** и дождитесь окончания восстановления.
6. После обогащения дождитесь сообщения **Файловая база сохранена**. Не закрывайте вкладку во время записи.

MADB содержит текущее состояние, финальные снимки, историю изменений, накопленный инвентарь, известные модели, IP-маппинг и настройки. Для переноса на другой компьютер скопируйте всю папку данных либо один актуальный файл `database/mac-analyzer-data.madb`.

## Открытие на другом компьютере или в другом браузере

1. Скопируйте папку программы и папку данных без изменения внутренней структуры.
2. Откройте HTML в Chrome или Edge.
3. Нажмите **Локальная база → Выбрать локальную папку** и укажите скопированную папку.
4. Подтвердите чтение существующей MADB и дождитесь 100% импорта.
5. Проверьте число устройств и снимков во вкладках **Данные**, **История** и **Аналитика**.

Разрешение на папку является настройкой конкретного браузера. Новый браузер попросит выбрать папку повторно, но сами данные останутся в MADB.

## Если браузер не поддерживает прямую запись в папку

Используйте **Открыть файл MADB** для импорта. После работы нажмите **Сохранить MADB отдельно** и замените старую копию новым скачанным файлом. До экспорта изменения находятся в IndexedDB только этого профиля браузера.

## Backend и SQLite

При запуске через `START_MAC_ANALYZER.cmd` программа использует общую SQLite-базу из `data/databases/`. Это рекомендуемый режим для нескольких браузеров на одном компьютере: backend автоматически восстанавливает последний успешный Final и историю.

В инженерном режиме на вкладке **Данные** доступны:

- **Скачать базу SQLite** — создать резервную копию;
- **Загрузить базу SQLite** — безопасно импортировать поддерживаемые таблицы;
- **Проверить/оптимизировать SQLite** — проверить целостность и выполнить обслуживание;
- **Импортировать SQLite Python-версии** — добавить сведения старой версии без очистки активной базы.

Импорт не должен заменять рабочую БД пустой базой. Перед загрузкой проверяются заголовок SQLite и `integrity_check`, затем данные объединяются добавочно.

## Что делать, если данные не появились

1. Проверьте статус в верхней панели: должно быть указано **SQLite подключена** либо **Папка подключена**.
2. Повторно откройте **Локальная база** и нажмите **Прочитать папку в браузере**.
3. Дождитесь завершения шкалы; большие истории восстанавливаются порциями.
4. Не открывайте одну MADB одновременно на запись в нескольких вкладках.
5. Если файл повреждён, не удаляйте его: восстановите последнюю копию из `backups`.

## Резервное копирование

- Создавайте копию MADB или SQLite перед крупным импортом.
- Храните не менее двух последних успешных копий.
- Не переименовывайте файл `database/mac-analyzer-data.madb` внутри подключённой папки.
- Не редактируйте MADB и SQLite текстовым редактором.
- После восстановления сверяйте количество Final, Inventory и записей истории — эти значения могут различаться, поскольку Inventory содержит все когда-либо известные устройства.
