# Changelog

## 1.0.56

- Фильтры хронологии помещения стали каскадными: ТБ ограничивает города,
  город — площадки, площадка — этажи, этаж — помещения; поиск понимает разные
  форматы одного MAC-адреса.
- Иерархия `ТБ, Город, Площадка, Этаж, Помещение` распознаётся не только в
  адресе, но и когда вся строка находится непосредственно в колонке помещения.
- Сравнение Final использует несколько устойчивых идентификаторов устройства,
  поэтому смена MAC не превращается в ложную пару «удалено + добавлено».
- Пустые поля в промежуточных старых снимках наследуют последнее известное
  значение и больше не создают ложные изменения «пусто → значение».
- DDIO заполняет отсутствующий IP основного устройства по MAC, сохраняет все
  возможные адреса и показывает их в раскрываемом предупреждении при смене IP
  коммутатора.
- Добавлено отдельное руководство по автономной MADB и локальной SQLite-базе.
- Усилена обработка отсутствующего Device ID в Web Worker и строкового
  формата Possible IPs в сравнении снимков.
- При повторном открытии актуальные SQLite Final заново сверяются с сервером;
  устаревшие backend-ссылки из autosave не вытесняют реальные снимки текущей
  базы, а браузерные снимки сохраняются.

## 1.0.55

- Добавлены поиск и фильтры хронологии помещения по ТБ, городу, площадке,
  этажу и помещению с разбором иерархии из строки через запятую.
- Добавлена проверка «изменились ли все устройства помещения» между двумя
  последними финальными выгрузками с подробным списком устройств.
- «Динамика изменений» агрегируется по месяцам, заполняет пропущенные месяцы и
  показывает в подсказке число затронутых переговорных и MAC-адресов.
- Хронология MAC показывает полные карточки «предыдущий Final → новый Final» и
  не дублирует одно событие из рассчитанной и сохранённой истории.
- Исправлена фильтрация вкладок критических и остальных изменений: в раскрытии
  отображаются только события, соответствующие активной вкладке.

## 1.0.48

- Устройства только из второго файла больше не отбрасываются и сохраняют источник каждого поля.
- IP устройства автоматически берётся из DDIO, если его нет в SR/файле обогащения.
- Введена единая сильная идентификация по MAC, серийному номеру и ID устройства.
- Последний финальный результат используется как безопасный источник известных непустых значений.
- Конфликты источников сохраняют выбранное и альтернативное значения и попадают в критическую аналитику.
- Отдельная страница «Изменения IP» полностью удалена; смена IP коммутатора показана в критических изменениях вместе с IP устройства из DDIO.
- Пользовательский режим сразу открывает поиск и таблицу устройств.
- SQLite хранит hostname, серийный номер, ID/название устройства, происхождение полей и конфликты; миграция только добавочная.
- Повторная одинаковая запись истории стала идемпотентной, пустые значения не затирают inventory.
- Добавлены регрессии SR/обогащения/DDIO, смены коммутатора, конфликтов, persistence и 10 000 записей.

## 1.0.47

- Исправлены пустые Chart.js canvas: нормализация данных, No Data и ошибка загрузки.
- Все даты хронологий приведены к UTC; интервалы вычисляются по миллисекундам.
- Добавлена мгновенная фильтрация помещений и хронологии по городу.
- Устранено «дерганье» виртуальной таблицы, закреплены шапка и высота строк.
- Навигация сгруппирована в сворачиваемые разделы.
- DDIO принимает только корректные IPv4/IPv6 и показывает типизированные IP-бейджи.
- API DDIO получил timeout, try/catch и человекочитаемые ошибки.
- Добавлены Prettier и новые регрессионные тесты графиков, времени и IP.
- Полный релиз возвращён в исходный репозиторий `Mac_analyzer_Pro`.

## 2.0.0 (внутренний этап рефакторинга; не отдельная линия продукта)

- Полный DDIO Possible IP dropdown с критической подсветкой и Device ID.
- Полная горизонтальная MAC-хронология с раскрытием деталей.
- IndexedDB v8: безопасная миграция и индексы для Smartroom, MAC, коммутатора и времени.
- Перенос известных моделей из localStorage в `KnownModels`.
- Страница 50 строк, виртуальный рендер больших таблиц, Worker и кеш вкладок.
- Усиленная валидация Smartroom ID и человекочитаемая обработка ошибок.
