# MAC Analyzer Pro v1.0.54

## Исправления аналитики

- Исправлено переключение «За период» / «Между выгрузками»: выбранный режим
  больше не подменяется backend после восстановления текущего Final.
- Сравнение за период использует финальные снимки на границах диапазона, а при
  их отсутствии — постоянный журнал изменений. Записи без корректной даты
  безопасно пропускаются, обратный диапазон нормализуется.
- Исправлены ключи сравнения IndexedDB в автономном HTML. Одинаковое устройство
  теперь определяется одинаково при индексировании предыдущей и проверке новой
  выгрузки, без ложной пары «добавлено + исчезло».
- Полные числовые итоги сравнения больше не пересчитываются по ограниченному
  списку видимых строк. Карточки и журнал показывают точные значения добавлений,
  исчезновений, изменений, критических событий и затронутых помещений.
- Добавлен фактический интервал между выгрузками/границами периода.
- «Динамика общего числа устройств» теперь показывает количество устройств в
  каждом финальном снимке с видимыми числовыми значениями, а не количество
  событий изменения полей.

## Надёжность и комплект поставки

- Добавлены регрессионные тесты для старых периодов, выбора граничных снимков,
  постоянной SQLite-истории, стабильного browser identity key и числовых итогов.
- Закрытие или перезагрузка вкладки во время фонового ответа больше не создаёт
  ложную ошибку API и повторный traceback в серверном журнале.
- Интерфейс проверен в браузере для обоих режимов: 1 добавление, 1 исчезновение,
  1 изменение и 1 критическое событие отображаются согласованно; ошибок и
  предупреждений в консоли нет.
- Полный архив `MAC-Analyzer-v1.0.54-Full.zip` содержит программу, исходники,
  автономный HTML, Windows runtime, OUI-справочники и сохранённые данные/историю
  из полного комплекта v1.0.27.
