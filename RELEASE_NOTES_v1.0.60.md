# MAC Analyzer Pro v1.0.60

Полный выпуск с автоматическим CMD/Python-запуском без административных прав.

## Запуск

- Основной пользовательский файл — `START_MAC_ANALYZER.cmd`.
- CMD сначала запускает `scripts/portable_launcher.py` через локальный либо
  системный Python 3.10+.
- `server.py` открывается в отдельной Python-консоли обычного пользователя.
- Браузер открывается автоматически только после успешной проверки
  `http://127.0.0.1:<port>/api/health`.
- Если порт 8080 занят другим приложением, автоматически выбирается свободный
  порт из ближайшего диапазона.
- Повышение прав, UAC и `RunAs` не используются.
- На компьютере без Python полный пакет использует резервный backend,
  собранный с манифестом `asInvoker`.

## Надёжность

- Добавлена проверка запуска из перенесённой папки с кириллицей в пути.
- CMD корректно передаёт параметры `--port`, `--no-browser`, `--hidden` и
  `--validate-only` без повреждения пути с завершающим обратным слешем.
- PID сохраняется только после успешной проверки готовности.
- При падении backend или превышении времени ожидания пользователь получает
  понятное сообщение, а браузер не открывает неработающую страницу.

## Проверки

Релиз проверяется полным frontend/backend regression, реальным запуском через
`START_MAC_ANALYZER.cmd`, health check, автономной HTML-сборкой, API/UI smoke,
проверкой Windows-манифеста и сборкой полного архива с базой и историей v1.0.27.

Для полной программы скачивайте **MAC-Analyzer-v1.0.60-Full.zip**.
