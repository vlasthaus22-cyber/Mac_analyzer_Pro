# MAC Analyzer Pro v1.0.80

## Исправление локальной аналитики

- Устранена причина пустых dashboard и диаграмм в автономном режиме: старые
  Final могли оставаться только в метаданных после автоматической очистки их
  строк из IndexedDB.
- Устройства, производители, модели, помещения, коммутаторы и заполненность
  теперь рассчитываются по полному выбранному Final, а не по странице из 50
  строк.
- Показатели «Изменённые», «Отсутствуют», «Без изменений», изменения кодеков и
  помещений строятся по двум полным выбранным Final.

## Постоянная папка Final

- Все успешные финальные обогащения сохраняются порциями в локальной IndexedDB
  с признаком `storageFolder: Final`.
- Автоматическое удаление старых Final при новом обогащении отключено.
- Добавлено отдельное компактное хранилище `FinalAnalytics`: агрегаты dashboard
  и точное сравнение с предыдущим Final сохраняются один раз и повторно
  используются без backend.
- При запуске фактическое содержимое IndexedDB сверяется с autosave, поэтому
  потерянная ссылка интерфейса больше не скрывает сохранённый Final.

## Совместимость и безопасность

- Схема IndexedDB обновляется с версии 11 до 12 без удаления пользовательских
  данных.
- Запись Final остаётся порционной и не создаёт вторую полную копию набора в
  памяти.
- Ошибка аналитического индекса не повреждает последний успешно записанный
  Final.
