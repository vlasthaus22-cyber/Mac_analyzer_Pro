# MAC Analyzer Pro v1.0.76

Полный выпуск с согласованной аналитикой, ускоренным обогащением и удалённым
функционалом оповещений.

## Аналитика, диаграммы и dashboard

- Исправлено рассогласование после нескольких Final: сравнение, карточки,
  диаграммы и drill-down теперь строятся по одной выбранной паре снимков.
- Исправлены ложные нули и данные от последнего активного снимка при просмотре
  более раннего интервала.
- Backend и автономный IndexedDB-режим используют одинаковый comparison Final.
- Динамика общего числа устройств показывает всю доступную последовательность
  Final, а не только последние двадцать точек.
- Убран промежуточный отчёт по первым 50 строкам при наличии полного сохранённого
  Final: интерфейс показывает загрузку, затем атомарно выводит полные показатели.
- Статистические боковые панели используют один проход по истории вместо
  повторного полного разбора одних и тех же снимков.

## Производительность обогащения

- Повторно используемые SmartRoom/DDIO-файлы массового плана кешируются после
  первого разбора. Кеш ограничен восемью файлами и не создаёт неограниченный
  рост памяти.
- Backend сохраняет одно SQLite-соединение во время подсчёта динамики всех
  Final-снимков и декодирует тела по одному.
- Из пути обычного и массового обогащения удалены сетевые вызовы оповещений.

## Удаление оповещений

- Удалены настройки Email, Telegram и Slack из UI.
- Удалены endpoints `/api/notifications`, тестовые отправки и события анализа.
- Удалён интеграционный notification-service. Устаревшая таблица остаётся
  неактивной только для безопасной обратной совместимости существующих SQLite.

## Проверка и комплект

- Добавлены регрессии выбранной пары из трёх Final и аналитики после восьми Final.
- Проверены dashboard, Chart.js-графики SmartRoom, массовое обогащение, API/UI,
  автономный HTML и повторное обогащение 200 000 строк в трёх циклах.
- Релиз содержит один архив `MAC-Analyzer-v1.0.76-Full.zip`: готовый Windows
  runtime, автономный HTML, полный каталог исходников, тесты, OUI и очищенные
  рабочая/историческая SQLite без секретов и пользовательских raw-файлов.
