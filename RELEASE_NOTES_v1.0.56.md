# MAC Analyzer Pro v1.0.56

Полный релиз исправляет хронологию помещений, каскадные фильтры, сравнение
финальных обогащений и DDIO-подстановку IP.

## Исправлено

- Хронология помещения снова строится по двум последним финальным снимкам.
- Фильтры ТБ → Город → Площадка → Этаж → Помещение стали зависимыми: значения
  другой площадки или этажа больше не попадают в последующие списки.
- Общий поиск работает по Smartroom ID, иерархии, MAC, IP, IP коммутатора,
  hostname, Device ID, serial, производителю и модели.
- Кнопка «Изменились все устройства?» учитывает добавленные, удалённые и
  изменённые устройства выбранной переговорной.
- Аналитика сопоставляет предыдущий и новый Final по нескольким сильным
  идентификаторам и не теряет прежнее непустое значение из-за пустой ячейки в
  промежуточной выгрузке.
- Смена MAC стабильного устройства отображается как «было → стало», а не как
  две ложные записи удаления и добавления.
- Если у устройства основного файла отсутствует IP, DDIO может заполнить его
  по точному MAC, даже когда SmartRoom не содержит это устройство.
- При смене IP коммутатора предупреждение раскрывает все корректные IP данного
  MAC, найденные в DDIO.
- Хронология и месячная аналитика учитывают также исчезнувшие устройства.
- Добавлена инструкция `docs/LOCAL_DATABASE_GUIDE.md` для автономной MADB и
  backend SQLite-базы.
- Добавлена защита обработки отсутствующего Device ID при сравнении IP
  коммутаторов и строкового формата Possible IPs при сравнении снимков.
- Устранена потеря актуальных Final после повторного открытия: устаревшие
  backend-ссылки из autosave теперь сверяются с текущей SQLite и не вытесняют
  реальные снимки.

## Проверка

Проверено: 100/100 Python-тестовых файлов (339 функций), все JavaScript-тесты,
ESLint, Prettier и сборка автономного HTML. Повторное SQLite-обогащение:
200 000 строк × 3 запуска; агрегация Smartroom на 10 000 строк — 119 мс
в тестовом окружении (не гарантия времени на другом компьютере).

В браузере проверены каскад площадка/этаж/помещение, поиск, детали изменения
всех устройств комнаты, сравнение двух Final и раскрытие DDIO-адресов.
Ошибок консоли в этих сценариях не обнаружено.

Полный ZIP содержит актуальные исходники, автономный HTML, Windows-приложение
с runtime и сохранённую базу/историю из опубликованной v1.0.27. Текущая локальная
пользовательская база не включается. Сохранённые секреты очищаются в копии
релизной базы. Новый браузер в автономном режиме требует повторного разрешения
на папку MADB — это ограничение безопасности браузера, а не потеря данных.
