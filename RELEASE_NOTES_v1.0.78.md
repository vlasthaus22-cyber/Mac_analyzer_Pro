# MAC Analyzer Pro v1.0.78

Релиз исправляет критическую подмену полной аналитики первой страницей таблицы.

## Исправления

- После выхода из вкладки «Аналитика» и при автоматическом обновлении количество
  устройств больше не падает до 50.
- Временная ошибка backend, IndexedDB или поздний ответ старого запроса не
  перезаписывают полный dashboard неполным предпросмотром.
- При повторном входе аналитика заново проверяет полный Final, а при краткой
  недоступности источника показывает последний успешный полный расчёт.
- Аналитический текстовый отчёт и основные диаграммы защищены от той же подмены.
- Сохранение настроек dashboard в автономном режиме не пересчитывает показатели
  только по загруженной странице.

## Проверка

- Добавлен исполняемый тест жизненного цикла для Final из 12 237 устройств при
  50 строках в UI-предпросмотре.
- Проверены выход со вкладки, повторный вход, устаревший асинхронный ответ,
  кратковременная ошибка полного источника и восстановление кеша.
- Выполняются полный набор backend/frontend/API/UI/SQLite-тестов, сборка
  автономного HTML и проверка release-архивов.

## Состав выпуска

- `MAC-Analyzer-v1.0.78-Full-Program.zip` — полная программа, исходники, тесты,
  автономный HTML, Windows runtime, OUI и чистая рабочая SQLite.
- `MAC-Analyzer-v1.0.78-History-Database.zip` — очищенная историческая SQLite с
  MAC/model/history для штатного импорта без публикации секретов.
