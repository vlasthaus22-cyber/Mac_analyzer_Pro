# MAC Analyzer Pro v1.0.49

Полностью проверенный релиз логики трёх источников и постоянной истории.

## Основные исправления

- Зафиксирована последовательность: основной файл → SmartRoom → DDIO → предыдущий финальный снимок → сопоставление → новый финальный снимок → inventory → история → аналитика.
- SmartRoom-only устройства сохраняются, включая записи без MAC, если присутствует надёжный серийный номер или Device ID.
- DDIO-only строки не создают ложные устройства. DDIO заполняет отсутствующий IP только после надёжного сопоставления, а `Possible_IPs` остаются диагностической подсказкой.
- Device IP и Switch IP разделены; смена Switch IP сравнивается с предыдущим финальным состоянием.
- Единый identity resolver использует MAC, Serial Number и Device ID. IP, Switch IP и hostname не объединяют устройства самостоятельно.
- Добавлены стабильный `internalDeviceId`, уровень уверенности, происхождение каждого поля и явная фиксация конфликтов.
- Пустые значения новой выгрузки не затирают известные достоверные данные.
- Финальный снимок, resolved inventory и история сохраняются одной SQLite-транзакцией; повторное одинаковое обогащение идемпотентно.
- Исправлен поиск по устройствам без MAC: hostname, Serial Number, Device ID/name, IP, Switch IP, адресу, комнате и Smartroom ID.
- Исправлена несовместимость версий IndexedDB 8/10, из-за которой вкладка «Аналитика» могла показывать ошибку.
- Исправлено падение backend при восстановлении финального снимка с устройством без MAC.
- Обновлены безопасные аддитивные миграции и импорт resolved inventory/history.
