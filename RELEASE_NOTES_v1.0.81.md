# MAC Analyzer Pro v1.0.81

## Новое: отклонения IP коммутатора в переговорной

- На dashboard аналитики добавлена карточка **«Отклонения IP коммутатора»** с
  индикатором **NEW** и количеством затронутых переговорных.
- Клик по карточке открывает список: Smartroom ID, помещение, адрес,
  доминирующий (ожидаемый) IP коммутатора, распределение всех IP и оборудование
  с отклонением.
- MAC-адрес в списке открывает карточку и хронологию соответствующего устройства.
- Алгоритм исключает ложные срабатывания: нужны минимум три устройства с
  известным IP, уникальное строгое большинство и хотя бы один другой IP.
  Неизвестные IP и распределение 1:1 не считаются отклонением.

## Надёжность и производительность

- Один и тот же алгоритм используется автономным HTML, потоковой IndexedDB и
  Python/SQLite backend.
- Потоковый расчёт хранит только счётчики и ограниченную диагностическую выборку,
  поэтому не создаёт вторую полную копию большого Final в памяти.
- Индекс аналитики Final обновлён до версии 3; старые индексы автоматически
  пересчитываются из сохранённых частей снимка без удаления пользовательских данных.
- При запуске восстанавливаются IndexedDB, ранее подключённая папка программы и
  MADB; пустое состояние не перезаписывает последний успешный Final.

## Проверки

- Полный проектный набор: 105/105 файлов тестов, 388 функций.
- Покрыты строгий сценарий 4:1, отсутствие ложного срабатывания 1:1,
  потоковый IndexedDB-кэш и backend payload.
- Пройдены API/UI smoke, трёхисточниковое обогащение, массовое обогащение,
  повторное обогащение и стресс-тест 200 000 строк × 3 запуска.
- Автономный HTML собирается и проходит синтаксическую проверку.

## Полный архив

Release содержит один файл `MAC-Analyzer-v1.0.81-Full.zip`: автономный HTML,
Windows runtime, backend, весь исходный код, тесты, OUI, чистую рабочую SQLite и
очищенную историческую базу v1.0.27. Чувствительные настройки, токены, пароли,
сессии, исходные выгрузки и журналы исключены.
