# MAC Analyzer Pro v1.0.50

## Исправлено

- Устранён сбой обогащения примерно на 86%: при сохранении браузер больше не
  держит одновременно временную и финальную полные копии результата в IndexedDB.
- Сохранение Final выполняется порциями в атомарных транзакциях; при ошибке новый
  незавершённый снимок удаляется, а предыдущий успешный Final остаётся активным.
- Индикатор выполнения отражает реальные этапы: validation, parsing,
  normalization, main device creation, SmartRoom, DDIO, previous final,
  identity/conflicts, database save, history и completed.
- При ошибке показываются run ID, этап, обработанные строки, источник, устройство
  и технические подробности без секретов.

## Стратегия количества устройств

- `NO_EXPANSION`: состав текущего Final определяется только уникальными
  устройствами основного файла. SmartRoom и DDIO только обогащают совпадения.
- `ALLOW_EXPANSION`: основной файл остаётся базой; SmartRoom может добавить
  достоверно идентифицированное отсутствующее устройство.
- DDIO в обоих режимах не создаёт отдельные устройства. Несколько lease,
  reservation и Possible IPs остаются дочерними данными одного устройства.
- Previous Final используется для идентификации, восстановления значений и
  истории, но не возвращает отсутствующие устройства в текущий Final.
- Создание устройства централизовано; для добавленных и отклонённых кандидатов
  сохраняется объяснимое решение и набор сильных идентификаторов.

## Проверки

- Сценарии количества 100/150/500, переключение режимов 100 → 120 → 100,
  повторные запуски и стабильность внутренних ID.
- Реальный браузерный стресс-тест: три цикла по 100 000 устройств, без полного
  чтения XLSX в память и без оставшихся временных строк после commit.
- SQLite stress: 200 000 строк, три последовательных запуска.
- Rollback-тесты SQLite и IndexedDB, API/UI smoke, автономная HTML-сборка,
  frontend/backend regression-набор, lint и синтаксические проверки.

## Артефакты

Релиз содержит полный исходный проект, автономный HTML и готовый Windows-пакет
с чистой инициализированной базой. Пользовательские локальные базы, импорты,
секреты, токены и журналы в публичный релиз не включаются.
