# MAC Analyzer Pro v1.0.53

## Исправленные ошибки

- Исправлены пустые графики при первом открытии вкладки «Аналитика» после
  восстановления SQLite/IndexedDB. Chart.js теперь получает совместимые
  числовые данные и реально перерисовывает canvas после загрузки состояния.
- Исправлена хронология помещений: отображаются добавления, удаления,
  перемещения между коммутаторами/портами и подтверждённые изменения полей.
- Исправлена хронология MAC: сохранена полная цепочка до 500 загруженных записей
  каждого типа, убраны дубли browser/backend, восстановлен порядок от первого
  появления к текущему и корректные даты/интервалы UTC.
- Исправлена классификация критических изменений для русских и технических
  названий полей. Пустое новое поле больше не выдаётся за реальное изменение.
- Некорректные MAC больше не обрезаются до ложного валидного адреса. Каждая
  отклонённая строка содержит объяснение, исходное значение и рекомендацию;
  полностью пустые строки не засоряют список ошибок.
- Повторяющиеся Smartroom/DDIO строки одного устройства объединяются как
  атрибуты и альтернативы, а не превращаются в дополнительные события или
  устройства.

## Производительность и проверка

- Агрегация Smartroom выполняется в Web Worker порциями; тест 10 000 устройств
  укладывается в целевой предел 500 мс.
- Добавлены регрессии для графиков, обеих хронологий, диагностики MAC,
  нормализации изменений и сравнения последовательных Final.
- Автономный HTML, Windows runtime, исходники, тесты и сохранённые данные
  v1.0.27 входят в полный архив `MAC-Analyzer-v1.0.53-Full.zip`.
