# MAC Analyzer Pro v1.0.71

Полный выпуск с исправлением DDIO-IP, массового сопоставления колонок,
аналитики, поиска по истории и хронологии MAC.

## Исправлено

- Пустой IP устройства заполняется из DDIO только по точному MAC и независимо
  от логики смены IP коммутатора. Существующий IP не перезаписывается.
- DDIO fallback работает даже при отключённом переносе IP из SmartRoom.
- Dashboard принудительно пересчитывается при смене фильтра, периода или пары
  Final; ошибочный результат больше не кешируется на 30 секунд.
- Фоновые панели запускаются и в автономном IndexedDB-режиме, не блокируя KPI.
- Хронология первого Final больше не показывает ложное «Не заполнено → значение».
- Сравнение Final показывает полные состояния «Было» и «Стало», изменённые поля
  выделяются цветом.
- Универсальный поиск использует накопительный реестр всех Final и объединяет
  повторные исторические строки одного MAC.

## Добавлено

- График MAC, которые неоднократно исчезали и снова появлялись между Final.
  По клику открывается список с устройством, помещением и частотой переходов.
- Проверка и ручная корректировка колонок для каждого цикла массового
  обогащения перед запуском.
- Явные пресеты колонок для Main, SmartRoom и DDIO, включая `CallingStarionID`,
  `NasIP`, `NasPortID`, `B_ReceiptTime`, `Column2/3/9/10`.
- Локальные именованные архивы состояния: создать, загрузить и удалить.

## Проверено

- DDIO fallback с отключённым SmartRoom-IP.
- Пресеты Main/SmartRoom/DDIO.
- Полная хронология MAC и отсутствие ложного пустого начального значения.
- Аналитика повторного исчезновения/возвращения MAC.
- Автономная HTML-сборка и синтаксис JavaScript.
- Реальный браузер: числовые KPI, графики, детализация MAC и поиск по всем Final.
- Полный набор проверок: 105/105 файлов, 374 тестовые функции.
- Нагрузочная проверка: три прохода по 200 000 строк без удержанного роста памяти;
  локальное сравнение 20 000 строк — 54,1 мс, агрегация SmartRoom 10 000 строк — 113 мс.
- ESLint, проверка синтаксиса, API/UI smoke и автономная HTML-сборка прошли.
