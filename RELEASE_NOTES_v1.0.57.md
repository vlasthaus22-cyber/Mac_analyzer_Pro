# MAC Analyzer Pro v1.0.57

Полный комплект программы с исправлениями пунктов 2 и 5.

## Исправления

- Пустые уровни в строке «ТБ, Город, Площадка, Этаж, Помещение» сохраняют
  позиции. Отсутствующий этаж больше не ломает фильтры и поиск.
- Автономная аналитика восстанавливает пустые поля предыдущего Final из
  ближайших более ранних финальных снимков, не изменяя сохранённые снимки.
- Непустые значения базового Final не заменяются. Будущие снимки и отдельные
  применения маппинга не используются; исторические устройства не добавляются
  в текущий состав.
- Неоднозначные совпадения и противоречащие стабильные идентификаторы
  исключаются из восстановления. В сравнении сохраняется идентификатор
  снимка-источника восстановленного значения.
- Обработка выполняется порциями IndexedDB, без загрузки всей истории в память.

## Проверки

Добавлены регрессионные тесты пустых уровней и IndexedDB: три повторных
сравнения, сохранность исходных снимков, ближайшие известные значения,
неоднозначность, конфликт идентификаторов, границы порций и ошибка чтения.
Выполняются полный набор тестов, ESLint, Prettier и сборка автономного HTML.

## Состав полного ZIP

Актуальные исходники, тесты и документация; автономный HTML; Windows-приложение
с runtime; сохранённая база и история из ранее опубликованной v1.0.27.
Текущая пользовательская база с этого компьютера не публикуется.

Для полного комплекта скачивайте **MAC-Analyzer-v1.0.57-Full.zip**.
Отдельный HTML не содержит SQLite-историю. Инструкция по MADB, SQLite и
переносу данных находится в Source/docs/LOCAL_DATABASE_GUIDE.md.
