# MAC Analyzer Pro v1.0.77

Полный выпуск с недельной аналитикой и уменьшенным основным архивом без потери
функционала или исторических данных.

## Недельная динамика изменений

- График «Динамика изменения MAC-адресов» теперь группирует события по неделям
  с понедельника по воскресенье.
- Несколько Final-выгрузок одной недели суммируются в один столбец.
- Пропущенные недели отображаются с нулевым числом изменений, поэтому временная
  шкала остаётся непрерывной.
- В подсказке столбца показывается количество затронутых переговорных и
  уникальных MAC-адресов.
- Недельная группировка применяется только к графику динамики MAC. «Добавленные
  и отсутствующие устройства» и «Общее число устройств» продолжают показывать
  точные последовательные Final без потери детализации.

## Уменьшение размера программы

- `MAC-Analyzer-v1.0.77-Full-Program.zip` содержит полную программу: готовый
  Windows runtime, автономный HTML, OUI, чистую SQLite, весь исходный код,
  тесты и инструменты.
- Историческая база вынесена в отдельный
  `MAC-Analyzer-v1.0.77-History-Database.zip`.
- База не удалена и не урезана: сохранены MAC-история, модели, производители,
  снимки и справочники. Секреты и инженерные сессии удалены из публичной копии.
- Для подключения базы распакуйте `mac_analyzer_history.db`, запустите основной
  пакет, войдите в инженерный режим и выберите «Данные → Загрузить базу SQLite».
  Импорт выполняется слиянием и не удаляет существующие данные.

## Проверка

- Полный набор backend/frontend/API/UI/SQLite-тестов.
- Повторное обогащение и bounded-memory тест на 200 000 строк.
- Отдельная регрессия недельной агрегации, включая несколько выгрузок одной
  недели и неделю без снимков.
- Проверка автономного HTML, Windows runtime и обоих release-архивов.
