# MAC Analyzer Pro v1.0.59

Полный выпуск с исправлением потери исходного файла при обогащении,
диагностикой реального этапа ошибки и ускоренными повторными переходами.

## Исправления

- Устранена причина ошибки «исходный файл отсутствует»: оригиналы основного,
  SmartRoom и DDIO-файлов сохраняются в IndexedDB даже при импорте через
  backend и остаются доступны для повторной загрузки кэша после перезапуска.
- Если подключена локальная папка данных, исходник дополнительно
  восстанавливается из её каталога `imports`.
- Несколько сохранённых оригиналов восстанавливаются параллельно, без
  последовательной задержки при открытии программы.
- Истёкший или удалённый backend-токен автоматически заменяется новым после
  повторной потоковой передачи сохранённого оригинала.
- Старые метаданные, для которых физического оригинала действительно нет,
  больше не дают этап «неизвестный». Интерфейс показывает этап
  «Восстановление исходных файлов», имя проблемного файла и сообщает, что
  последний успешный Final и история не изменены.
- Backend возвращает тот же машинно-читаемый этап `source-file-recovery`,
  поэтому пользовательская и техническая диагностика согласованы.
- Повторные переходы на неизменённые вкладки используют кеш сигнатуры и не
  запускают повторные API-запросы и полную перерисовку DOM.
- Потоковое автономное обогащение сохраняет записи пакетами по 1000 строк,
  уменьшая число транзакций IndexedDB при сохранении больших наборов.

## Проверки

Проверяются сохранение и восстановление исходного Blob через IndexedDB и
локальную папку, восстановление после cache miss, диагностический этап,
повторные переходы без перерисовки, полный frontend/backend regression,
автономная сборка и API/UI smoke.

Для полной программы скачивайте **MAC-Analyzer-v1.0.59-Full.zip**.
