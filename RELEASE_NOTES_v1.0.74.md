# MAC Analyzer Pro v1.0.74

Полный проверенный релиз с понятной структурой, запуском без прав администратора
и отдельным безопасным пакетом исторической базы.

## Структура релиза

- `START_HERE.cmd` — основной запуск готовой Windows-версии из корня архива.
- `MAC-Analyzer-Pro.html` — автономный браузерный режим без backend.
- `Windows-Portable` — готовая программа, backend, SQLite и OUI.
- `Source` — полный исходный код, тесты и инструменты разработчика.

Дополнительные HTML внутри `Source` являются исходниками, тестовыми стендами или
legacy-эталоном и не являются отдельными копиями программы для пользователя.

## Почему архивы имеют разный размер

`Full-Clean` содержит всю программу и чистую SQLite. `Full-History` дополнительно
содержит очищенную историческую SQLite размером около 373 МБ до сжатия. Именно
эта база, а не отсутствующий код, объясняет размер старых релизов около 90 МБ.

## Безопасность исторического пакета

- Сохранены MAC-история, модели, производители и накопленные сопоставления.
- Удалены инженерные сессии, ключи, пароли, токены и webhook-значения.
- Не включены исходные XLSX/CSV, workspace cache, логи, экспорты, временные файлы,
  старые копии backup и исходный несанитизированный архив.

## Проверка

- Полный автоматический набор frontend/backend/API/build/stress-тестов.
- Проверка SQLite `PRAGMA integrity_check` для активной и исторической базы.
- Проверка наличия всех Git-tracked исходников и обязательных runtime-файлов.
- Проверка запуска через выбранный Python без прав администратора.
