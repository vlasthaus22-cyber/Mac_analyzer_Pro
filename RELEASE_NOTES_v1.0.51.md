# MAC Analyzer Pro v1.0.51

## Исправлено

- Устранена ошибка `LocalMap`/`VersionError` после повторного открытия:
  резервный загрузчик больше не открывает общую IndexedDB с устаревшей версией.
- Все браузерные модули переведены на единую схему IndexedDB v11 с индексом по
  IP коммутатора.
- Локальный финальный снимок восстанавливается до синхронизации с SQLite и не
  удаляется, если backend не содержит его идентификатор.
- Компактный autosave больше не затирает пустыми объектами локальные правила
  производителей, моделей, IP-адресов и Smartroom.

## Автоопределение физического адреса

- История предыдущих финальных обогащений агрегируется по IP коммутатора.
- Адрес подставляется только при консенсусе не ниже 90% и минимум двух
  непустых наблюдениях.
- В Final сохраняются `addressSource`, `addressConfidence` и источник поля.
- Конфликтные исторические адреса не выбираются случайно и не заменяют текущее
  непустое значение.
- Одинаковая логика работает с SQLite backend и в автономном IndexedDB-режиме.

## Проверки

- Регрессия 90%/80%: 9 из 10 одинаковых наблюдений применяются, 8 из 10 — нет.
- Повторное открытие: браузерный Final имеет приоритет над старым пустым autosave.
- Проверка обновления IndexedDB v10 → v11 и отсутствия открытия схемы v4.
- Полный набор unit/integration/API/UI/memory тестов и автономная HTML-сборка.

## Полный пакет

Release содержит полный исходный проект, автономный HTML, готовый Windows-пакет
и сохранённую SQLite-базу с историей. Секреты, токены и временные файлы удалены
из публичного архива.
