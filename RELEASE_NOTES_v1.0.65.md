# MAC Analyzer Pro v1.0.65

Полный выпуск содержит актуальный исходный код, автономный HTML, Windows-
комплект, локальную SQLite-базу, OUI-справочники и совместимые данные полного
комплекта v1.0.27. Секреты, токены, пароли, webhook-адреса и инженерные сессии
исключаются из публикуемой копии.

## Исправлено

- Устранено падение обогащения на 5% с `NoModificationAllowedError`. Причиной
  был устаревший, заблокированный либо read-only дескриптор MADB. Основное
  сохранение в IndexedDB теперь завершается независимо; недоступная файловая
  синхронизация отключается до повторного подключения и не повреждает Final.
- Подготовка предыдущего Final включена в диагностируемые этапы процесса, поэтому
  ранние ошибки больше не отображаются как «неизвестный этап».
- В сопоставление файла №2 SmartRoom добавлена колонка **MAC дополнительного
  интерфейса**. Основной и второй MAC являются сильными псевдонимами одного
  устройства, сохраняются без размножения строк и используются повторно.
- DDIO заполняет отсутствующий IP устройства при совпадении основного, второго
  либо ранее сохранённого альтернативного MAC. Валидный существующий IP не
  перезаписывается; источник остаётся `DDIO`.
- Хронология MAC нормализует старые русские и канонические названия полей,
  восстанавливает «было» из предыдущего полного Final и отбрасывает ложные
  события, где восстановленное старое значение совпадает с новым.
- Аналитика показывает локальную сводку до завершения тяжёлой агрегации и не
  выполняет второй одинаковый запрос dashboard после загрузки первого.

## Проверка

- Полный штатный набор frontend/backend, API/UI smoke, синтаксические и lint-
  проверки.
- Регрессия заблокированного файлового дескриптора MADB.
- Main MAC → второй MAC SmartRoom → IP DDIO при пустом IP устройства.
- Хронология с разреженной legacy-записью и полным предыдущим Final.
- Три повторных цикла обогащения и bounded-memory стресс на 200 000 строк.
- Сборка автономного HTML и полного релизного ZIP с базой и историей.
