# MAC Analyzer Pro v1.0.52

## Критическое исправление

- Устранён `ReferenceError: localDeviceMap is not defined`, который возникал
  после обогащения во время сравнения предыдущего и нового Final.
- Восстановлена единая нормализованная MAC-карта устройств.
- Добавлен исполняемый тест добавления, изменения и исчезновения устройств.
- ESLint теперь проверяет `no-undef` для browser/Node-окружения и останавливает
  сборку при повторном появлении неопределённого имени.

## Производительность

- Сравнение Final больше не создаёт две полные Map-копии наборов.
- Для большого числа IP коммутаторов история IndexedDB читается одним
  последовательным проходом вместо тысяч отдельных cursor-запросов.
- Для малых выборок сохранён прямой поиск по индексу `by_switch`.

## Полный пакет

Release содержит текущий исходный проект, автономный HTML, Windows-версию,
SQLite-базу и сохранённую историю. Секреты и временные файлы в архив не включены.
