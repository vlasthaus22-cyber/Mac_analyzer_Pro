# MAC Analyzer Pro v1.0.64

Полный выпуск с актуальным исходным кодом, автономным HTML, готовым Windows-
комплектом, локальной SQLite-базой, OUI-справочниками и совместимыми данными
предыдущего полного комплекта. Перед публикацией сохранённые секреты, токены,
пароли, webhook-адреса и инженерные сессии удаляются из копии релиза.

## Исправлено

- IP устройства с пустым либо служебным значением (`Не определено`, `-`,
  `null`) автоматически заполняется из DDIO при точном совпадении
  нормализованного MAC-адреса.
- Исправлена одинаковая логика DDIO-подстановки в серверном и автономном
  потоковом режимах; существующий валидный IP не перезаписывается.
- Для подставленного адреса сохраняются источник `DDIO`, набор `Possible IPs`
  и отдельный счётчик успешно заполненных IP.
- Интерфейс сопоставления DDIO сокращён до четырёх однозначных полей:
  MAC/IP резервации и MAC/IP аренды.
- Удалены дубли DOM-идентификаторов аналитики, из-за которых показатель
  устройств без помещения и сводки могли обновляться в невидимом блоке.
- Раздел «Состав и качество данных» раскрыт по умолчанию и показывает число
  устройств без помещения, а также сводки по их производителям и моделям.

## Проверка

- Полный штатный прогон frontend/backend, API/UI smoke и синтаксические проверки.
- Регрессионный сценарий Main с пустым IP → SmartRoom без IP → DDIO с четырьмя
  колонками и несколькими возможными адресами.
- Повторное обогащение и bounded-memory стресс-тест на 200 000 строк.
- Проверка автономного HTML, полного исходного комплекта и Windows-пакета.
